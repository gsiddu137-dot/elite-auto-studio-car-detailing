# Elite Auto Studio — Beginner Website Project

A seven-page, dark luxury (black and gold) car detailing studio portfolio website built with HTML, CSS and vanilla JavaScript.

## Pages
1. Home — `index.html`
2. About — `about.html`
3. Services — `services.html`
4. Packages — `packages.html`
5. Gallery — `gallery.html`
6. Booking — `booking.html`
7. Contact — `contact.html`

## Run it in Visual Studio Code
1. Extract the ZIP file.
2. Open the `elite-auto-studio` folder in VS Code.
3. Install the **Live Server** extension (optional but recommended).
4. Right-click `index.html` and choose **Open with Live Server**.
5. Use the navigation bar to explore the pages.

You can also open `index.html` directly in a browser.

## Folder structure
- `css/style.css` — shared theme, layouts, responsive styling and components.
- `js/main.js` — mobile navigation and shared interactions.
- `js/booking.js` — front-end demo booking form validation.
- `js/gallery.js` — gallery category filters and image lightbox.
- `images/` — reserved for downloaded/local image assets.

## Beginner learning order
1. Open `index.html` and identify the semantic HTML sections.
2. Open `css/style.css` and change the CSS variables in `:root`.
3. Change the hero heading and service card content.
4. Open `js/main.js` and study the mobile navigation.
5. Test the gallery filters and booking form.

## Important notes
- This is a portfolio demo, not a live business website.
- Prices, testimonials, contact details and location are sample content.
- The booking form only validates in the browser. It does not send, store or create bookings.
- Images and Google Fonts are loaded from external services, so an internet connection is needed for those assets.
- Before using this for a real business, replace all sample details, use images you own or have permission to use, and connect a secure backend for bookings.
